# 📌 Project Overview

This project is an **interactive Swiggy Sales Dashboard** built entirely in **Microsoft Excel**. It transforms raw sales data into meaningful business insights through dynamic charts, KPIs, Pivot Tables, and interactive slicers.

The dashboard enables users to monitor sales performance, compare restaurant performance, analyze customer behavior, and identify business trends for informed decision-making.
